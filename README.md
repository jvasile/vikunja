# LL-Vikunja

This is the LibreLaunch edition of Vikunja.  It is a soft fork of the
[upstream](https://github.com/go-vikunja/vikunja) for the purposes of adding
some bits that make it work well on LibreLaunch.

## Contributing

Generally speaking, we prefer contributions target the upstream Vikunja project.
It doesn't do the ecosystem any good for us to have features that upstream
lacks.
